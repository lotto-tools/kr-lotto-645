# 로또 6/45 분석소 — 로또 번호 분석 · 세후 실수령액 계산 웹사이트

동행복권 **공식 회차 데이터 제1회~제1,250회(1,250회 전체)** 를 수집해 만든 정적 웹사이트입니다.
서버·데이터베이스 없이 HTML/CSS/JS만으로 동작하므로 GitHub Pages, Cloudflare Pages, Netlify 등에
그대로 올려 무료로 운영할 수 있습니다.

- 최신 회차: **제1,250회 / 2026-11-14 추첨 / 1, 5, 18, 23, 27, 28 + 보너스 8 / 1등 9명 각 3,103,164,459원**
- 데이터 수집일: 2026-11-16
- **운영 주소**: https://lotto-tools.github.io/kr-lotto-645/ (GitHub Pages, `main` / root)

## 2. 데이터

- **출처**: 동행복권 공식 홈페이지 `https://www.dhlottery.co.kr` (회차 조회 API
  `lt645/selectPstLt645InfoNew.do`). 기존에 널리 쓰이던 `common.do?method=getLottoNumber`는
  현재 홈으로 리다이렉트되어 사용할 수 없습니다.
- **범위**: 제1회(2002-12-07) ~ 제1,250회(2026-11-14), 총 1,250회, 누락 0건.
- **필드**: `r` 회차, `d` 추첨일, `n` 당첨번호 6개(오름차순), `b` 보너스번호,
  `w` 1~5등 당첨자 수, `a` 1~5등 1인당 당첨금, `s` 해당 회차 판매액.
- 임의로 만든 값은 없으며, 수집 후 회차 연속성·날짜(전부 토요일)·번호 범위·중복 여부를 검증했습니다.

### 주간 갱신

```bash
python3 tools/update_draws.py          # 새 회차만 추가 (매주 일요일 이후 실행 권장)
python3 tools/update_draws.py --full   # 전체 재수집
```

갱신하면 `data/draws.json`과 `data/draws.js`가 함께 다시 작성됩니다.
회차가 늘어나면 `index.html`의 회차 입력창 `max` 값(현재 1250)만 같이 올려 주세요.

## 3. 주요 기능

| 기능 | 설명 |
|---|---|
| 최신 회차 조회 | 등수별 당첨자 수·당첨금·**세후 1인 수령액**, 판매액, 회차 검색(1~1,250), 최근 10회 목록 |
| 번호 분석 | 최근 10/30/50/100/전체 구간 실시간 재계산, 45개 번호 빈도 막대·히트맵, 핫/콜드 넘버, 연속 미출현 TOP 10, 홀짝·고저·번호대 분포, 합계 분포, 연속번호·동반 출현 |
| 번호 생성기 | 고정수(최대 5)·제외수(다중)·홀짝 비율·연속번호 제외 옵션으로 5게임 생성 |
| 역대 시뮬레이터 | 생성 번호 또는 직접 고른 6개 번호가 1~1,250회에서 1~5등에 몇 번 해당했는지 즉시 조회 |
| 세금 계산기 | 2026년 소득세법 기준 1원 단위 계산, 구간별 내역 표, 빠른 입력(1~5등), 1,000원 필요경비 옵션 |
| 정보 페이지 | 수령 절차·기한·세율·건전 이용 안내, 개인정보처리방침, 이용약관 |

### 세금 계산 규칙

- 200만원 이하: 비과세
- 200만원 초과 ~ 3억원: **당첨금 전액**의 22% (소득세 20% + 지방소득세 2%)
- 3억원 초과: 3억원까지 22%, 초과분 33% (소득세 30% + 지방소득세 3%)
- 원 단위 미만 절사. 게임 구입금액 1,000원을 필요경비로 차감하는 옵션 별도 제공.
- 1등 3,103,164,459원 → 세금 991,044,270원, 실수령 2,112,120,189원 (실효세율 31.9%)

## 6. 배포

### GitHub Pages
1. 이 사이트는 `lotto-tools/kr-lotto-645` 저장소의 `main` / `/ (root)`에서 배포되어
   https://lotto-tools.github.io/kr-lotto-645/ 로 운영 중입니다.
2. 저장소 내용을 갱신해 push하면 1~2분 뒤 자동으로 다시 배포됩니다.
3. 처음 배포할 때는 Settings → Pages → Source: `Deploy from a branch` → `main` / `/ (root)`를 선택합니다.

### Cloudflare Pages
1. Cloudflare Pages → Create project → 저장소 연결.
2. Framework preset: **None**, Build command: 비움, Build output directory: `/`(또는 `lotto-site`).
3. 배포 후 커스텀 도메인을 연결합니다.
